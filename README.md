# Piano Lead Finder

React + Vite site hosted at [pianoleads.benyellow.com](https://pianoleads.benyellow.com).

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Starts local dev server at `http://localhost:5173`.

## Build

```bash
npm run build
```

Bundles `src/` into `dist/`.

## Deploy

```bash
npm run deploy
```

Builds and pushes `dist/` to the `gh-pages` branch on GitHub. GitHub Pages serves from that branch automatically.
